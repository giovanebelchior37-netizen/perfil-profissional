# Portfólio — Giovane Belchior

Portfólio pessoal desenvolvido com HTML5 e CSS3.

## Como visualizar
Abra o arquivo `index.html` no navegador.

## Personalização antes de publicar
1. No `index.html`, substitua `SEU-EMAIL@EXEMPLO.COM` pelo seu e-mail.
2. Substitua `SEU-USUARIO` pelos seus nomes de usuário do GitHub e LinkedIn.
3. Atualize os links dos projetos quando os repositórios estiverem publicados.
4. Revise as descrições dos projetos para refletir o que já foi implementado.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub (por exemplo, `meu-portfolio`).
2. Envie `index.html`, `style.css` e `README.md` para a branch `main`.
3. Acesse **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde a publicação. O GitHub exibirá o endereço do site na própria página Pages.
